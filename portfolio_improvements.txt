PORTFOLIO IMPROVEMENTS
======================

CONTENT
-------
1.  Hero text says "I craft Webflow sites" but you have never built a Webflow site based on your projects. Change it to reflect what you actually do.
2.  "What I Build" section mentions Webflow Development again, same problem.
3.  The Duffalos project has the exact same text in both overview and realizations fields in projects.ts. It is a copy paste that was never fixed.
4.  The Projects section description says "What starts as an idea becomes a clean, scalable website" which is identical to the "What I Build" section above it. Two sections should not share the same description text.
5.  The footer says 2025 but it is already 2026.

BROKEN OR DEAD CODE
-------------------
6.  Hero.tsx still has "Hi, I'm [Your Name]" as a placeholder and is imported nowhere. It is dead code sitting in your repo.
7.  ProjectDetail.tsx uses useRouter from next/router which is the old Pages Router. Your project uses the App Router so this will crash. The correct import is useParams from next/navigation.
8.  The Visual Showcase section at the bottom of ProjectDetail.tsx renders an empty glass div with no content inside it at all.
9.  Two images in HomeSections.tsx are loaded from Figma API URLs. These will be broken for anyone who is not logged into your Figma account.

CODE QUALITY
------------
10. HomeSections.tsx is over 300 lines and handles six completely different responsibilities. It needs to be split into separate components.
11. Two eslint-disable comments at the top of HomeSections.tsx are suppressing real warnings instead of fixing them. The any types should be replaced with proper TypeScript interfaces.
12. The skills array is defined inside the component so it gets recreated on every render. It should be moved outside the component or into a separate data file like data/skills.ts, similar to how you handled projects.
13. The Navbar is placed inside the main tag in layout.tsx instead of outside it. Semantically the navbar should be a sibling of main, not a child.
14. The MagneticButton is named Magnetic but has no magnetic effect. There is no mouse tracking or pull effect on it anywhere in the code.
15. The ContactModal external links for LinkedIn and GitHub are missing rel="noopener noreferrer" on the target="_blank" anchors, which is a security issue.

STYLING AND LAYOUT
------------------
16. The skills section has a hardcoded style height of 520px inline on the section element alongside a Tailwind min-h-screen class. These two conflict with each other.
17. globals.css defines :root twice in two separate blocks. The CSS variables should be consolidated into one :root block.
18. The body has font-family Arial set in globals.css but the layout uses Geist font via Next.js font variables. One of them will override the other inconsistently.
19. There is no og:image or social preview meta tag in layout.tsx, so when you share your portfolio link on LinkedIn or WhatsApp it will show a blank preview.
20. The metadata description in layout.tsx is very generic. "A dedicated developer" tells nobody anything useful about you.
